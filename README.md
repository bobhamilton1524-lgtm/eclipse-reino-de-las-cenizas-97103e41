# ECLIPSE: Reino de las Cenizas

Crea el proyecto web “ECLIPSE: Reino de las Cenizas”. Mantén el proyecto sin publicar; no despliegues ni conectes servicios externos. Es una migración del prototipo existente, no un juego nuevo. Conserva la estética de fantasía oscura pixel art, RPG 2D de acción, cámara centrada en el personaje, mapa explorable, controles táctiles para Android y teclado para PC, HUD de vida/experiencia/oro, personaje Guerrero, enemigos que persiguen y atacan, combate cuerpo a cuerpo, ciudad Umbravía y cripta/mazmorra. El prototipo original está disponible en el contexto anterior: usa su lógica y estructura como referencia. No agregues sistemas ni características no solicitadas; deja el proyecto preparado para seguir recibiendo instrucciones del usuario. No publiques ni despliegues bajo ninguna circunstancia.
